# Product Preview Card Component

A responsive e-commerce product preview card component built with semantic HTML5 and modern CSS (Flexbox & CSS Variables).

## Features
- Side-by-side desktop view transitioning smoothly to stacked mobile view
- Typography pairing using Google Fonts (Fraunces and Montserrat)
- Interactive 'Add to Cart' button with click state feedback
- Clean, accessible semantic markup

## Preview
Open `index.html` in your browser.
